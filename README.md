# links-kiripost-test

A **test copy** of the Kiripost link-in-bio page, to try it on a free web address before `links.kiripost.com` exists.

- Not the live page. It shows a "TEST COPY" bar and asks search engines not to list it (`noindex`, `robots.txt`).
- It reads the same published Google Sheet as the real page, and links to real kiripost.com stories.
- Story links are tagged `utm_source=links_test`, so test clicks stay out of the Instagram numbers.
- No Google Analytics is added here.
- The files come from `Documents\links-kiripost\site` (restyled "Clean newsroom" version of 2026-10-19). No `CNAME` file on purpose.
